# Swatch UV 点选工具计划

状态：`VERIFIED`（自动测试与图形界面事件模拟通过），待用户手动验收

## 目标

选中模型后，在左侧贴图窗口里直接点 swatch 格子，模型的 swatch UV（`UV1_Swatch`）即被缩成一点并放到该小格中心。执行后可在左下角 `Adjust Last Operation` 面板里继续微调。

不在本次范围：从活动模型复制格子给其它模型（后续单独做一个 operator）。

## Swatch 格子定义

- 整图 4×4 大格；每个大格横向 8 小格（颜色变化）、竖向 6 小格（粗糙度，越往下越粗糙）。
- 上面三行大格是三个色系：第 1 行暖色、第 2 行蓝色、第 3 行灰色。
  - 第 1、2 列是塑料，第 3、4 列是漆面；第 1 列对应第 3 列，第 2 列对应第 4 列，颜色相同，只是材质不同。
- 最下一行是金属，从左到右：高饱和冷色、高饱和暖色、低饱和冷色、低饱和暖色。
- UV 始终落在小格正中心，避免贴图缩小后串色。

## 可调参数（贴图窗口底部的参数条）

| 参数 | 取值 |
| --- | --- |
| 材质类型 | 塑料 / 漆面 / 金属 |
| 色组 | 塑料、漆面：Warm A / Warm B / Blue A / Blue B / Gray A / Gray B；金属：Cool Saturated / Warm Saturated / Cool Muted / Warm Muted |
| 颜色 | 1–8（从左到右） |
| 粗糙度 | 1–6（1 最光滑） |

- 塑料和漆面之间切换时色组不变，颜色随之一一对应。
- 金属的色组是单独一项参数：塑料/漆面与金属之间切换时，各自记住自己的色组，不再做“超过 4 取最后一个”的换算。
- 插件没有多语言支持，所以界面文字（参数名、选项名、顶部提示）全部用英文，与其它界面一致。例如悬停提示为 `Paint · Blue A · Color 5 · Roughness 3`。

## 操作流程

1. 选中模型，在 3D 视口 HST 面板里点 `Pick Swatch`（`Set Swatch` 按钮已从面板移除，其准备步骤由 `Pick Swatch` 自动完成）。
2. 如果还没准备好，自动完成 `Set Swatch` 已有的准备：打开左侧贴图窗口、补 swatch UV、套 swatch 材质、切换到渲染预览。
3. 进入点选状态：
   - 左侧贴图窗口底部出现一行参数条（材质、色组、颜色、粗糙度），侧栏不打开，色板保持原大小。参数条借用该窗口的工具设置栏，点选期间临时显示并翻到底部，结束后恢复原状。
   - 贴图左上角用 Blender 界面字号写一行操作说明（点格子或改参数条、Enter/Space/右键确认、Esc 取消）；状态栏也显示同样的说明。
   - 左键点贴图上的小格：立即应用到当前选中的模型，可以一直点来比较；参数条同步成这一格。
   - 改参数条：同样立即应用到当前选中的模型。活动模型跨多个格子时，参数条末尾显示 `Current: Mixed`。
   - 回车或空格：确认。
   - Esc：取消，本次点选改过的所有模型恢复原状。
   - 其它鼠标操作照常：左侧窗口可以缩放和平移，右侧视口可以旋转视角、换选模型，小键盘视角键和 Home 也可用。换选后再点格子，就改到新选的模型上。
   - 点选期间屏蔽其余键盘快捷键（例如 Tab、删除、撤销），避免中途改动模型导致取消时无法恢复。
4. 确认后整个点选过程只占一步撤销；参数条隐藏，不再出现左下角的调整面板。想再调，重新运行即可（会读出当前格子）。

作用范围：
- 物体模式下，改整个模型。
- 编辑模式下，只改选中的面，支持多个模型同时编辑。

## 对已设过 swatch 的模型再次运行

- 已有的 swatch UV 和 swatch 材质原样保留，不重建，也不移动位置。
- 进入点选时不改任何模型，只读取活动模型当前所在的格子（编辑模式下读取选中的面），显示在提示里，同时作为面板的初始值。
- 只有真正点了格子，才会覆盖选中模型（或选中的面）原来的格子。
- 如果活动模型的 swatch UV 没有缩成一点、分布在多个格子（例如手动摆过），就显示 `Mixed`；点格子后统一成一点。
- `Set Swatch` 同理：已有的 swatch UV 不动，只在新建时放到默认格子。以前放在贴图正中心的老模型不会自动迁移，需要用 `Pick Swatch` 重新点一次。

## 已知限制

- 右键固定为确认。如果你的 Blender 设成右键选择，在右侧视口里右键会直接确认并结束点选。
- 取消只恢复 swatch UV 的位置；进入点选时自动补上的 swatch UV（在默认格子）和 swatch 材质会保留。
- 点选状态依赖图形界面，常规回归只覆盖格子计算、应用和恢复；点选流程另用 Blender 的事件模拟跑过一次（见“验证记录”），点选手感仍需你手动验收。

## 实现拆分

- 公共代码：新增 swatch 工具文件（放在现有工具函数目录）
  - 格子参数与贴图坐标之间的双向换算。
  - 把指定模型或选中的面的 swatch UV 设为某个点。
  - 记录和恢复 UV，用于取消。
  - 把 `Set Swatch` 的准备步骤提取成共用函数，原按钮和新工具共用，原按钮行为不变。
- 新工具：放在现有 UV 相关工具文件里。点按钮时先检查选择和上下文，然后进入点选状态。
  - 面板参数挂在 WindowManager 上（不进入撤销历史、不存进文件），注册方式沿用现有 Scene 参数。
  - 参数条：点选期间给 Image Editor 的 Tool Header 追加参数绘制，并用 `screen.region_flip` 临时翻到底部；结束时移除并翻回原位置、恢复原显示状态。
- 面板：3D 视口 HST 面板里 `Set Swatch` 同一行加 `Pick Swatch` 按钮。
- 已知限制：贴图窗口很窄时参数条放不下会被截断，可拉宽窗口或 Ctrl+滚轮横向滚动；贴图窗口很扁时，色板最下一行可能被参数条挡住一点，缩放色板即可。

### 第二轮（交互改版）

- 用户反馈：进入工具时没有提示；确认后调左下角面板时，左侧贴图曾消失一次。
- 贴图消失的原因：首次运行时导入的 swatch 材质和贴图，会在调左下角面板触发“撤销再重做”时被撤掉，重做时又导入一份新的，左侧窗口仍指向旧贴图。改版后不再有左下角面板，这条路径已去掉。
- 改版：参数面板放进贴图窗口侧栏，点选期间一直显示；点格子与改面板双向同步；提示文字直接绘制在贴图上；确认后只占一步撤销。
- 图形界面事件模拟 26 项检查全部通过（该侧栏版本已被第三轮替换）。

### 第三轮（参数条移到贴图窗口底部）

- 用户反馈：侧栏占掉一整列，色板变小难点；提示文字太大。
- 改版：去掉侧栏面板及相关的“挪标签、缩放色板”处理；参数改为贴图窗口底部一行参数条；色板上只留一行操作说明，字号取 Blender 界面文字大小。
- 图形界面事件模拟 23 项检查全部通过：侧栏不打开、参数条在底部且不挡色板、点击生效并同步参数条、改参数条生效、点参数条不会误点格子、确认后参数条恢复原位且无左下角面板、一次撤销撤回整个点选、Esc 恢复（含参数条）、编辑模式只改选中面。
